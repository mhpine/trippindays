OFF THE ROAD PREMIUM — AUTO MODE

This changes the 3 Premium cards to true one-tap automatic features.

Trail Intelligence+
Basecamp Weekend+
Full Adventure+

On click, TrippinDays automatically:
1. uses the currently selected result if there is one
2. otherwise uses shared GPS / the starting location
3. searches the selected Off the Road activity
4. chooses the #1 ranked destination
5. builds the Premium trip

It does NOT change your hunting image paths.

INSTALL

Copy:
make-off-road-premium-auto.mjs

into:
C:\Users\mhpin\Documents\trippindays\trippindays

Run:

node .\make-off-road-premium-auto.mjs

Then restart:

npm run dev
